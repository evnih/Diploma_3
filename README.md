
# Diploma_3
=======
# Тестирование сайта Stellar Burgers
## Проверяется
### Регистрация:
-Нормальная регистрация

-Ошибка, если пароль короче 6 символов
### Вход в аккаунт:
-Через кнопку "Войти" на главной

-Через "Личный кабинет"

-Через форму регистрации

-Через форму восстановления пароля
### Конструктор бургеров:
-Переключение между разделами "Булки", "Соусы", "Начинки"

## Тестируем
с помощью Google Chrome и Яндекс.Браузер
Все результаты генерируются в отчет Allure
Для запуска тестов используются команды

mvn test (по умолчанию запускает в Google Chrome)

mvn test -Dbrowser=yandex (запускает тетсы в Яндекс браузере)

mvn allure:serve (формирует отчет Allure)

## Технические данные:
Java 11+
Maven
Браузеры Chrome и Yandex

## Как устроены тесты
Применен PageObject, страница сайта разложены по отдельным классам. 
В тестах для авторизации пользователь создается и удаляется через API, для это созданы отдельные классы.
